## 🔄 Единая система работы

```
┌─────────────────────────────────────────────────────────┐
│  TicksLoop (каждую 1 секунду)                          │
└─────────────────────────┬───────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│  Проверка активного процесса                            │
│  AutoDetectMngr.GetActiveProcessName(true)              │
└─────────────────────────┬───────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│  Проверка LocalIP (с кэшем)                             │
│  LocalIPDetector.DetectLocalIPForActiveProcess()        │
│  • Для нового процесса: немедленно (ResetCache)        │
│  • Для того же процесса: каждые 30 секунд              │
└─────────────────────────┬───────────────────────────────┘
                          ↓
                  ┌───────┴───────┐
                  │ IP изменился? │
                  └───────┬───────┘
                      ДА  ↓  НЕТ → выход
          ┌───────────────┴───────────────┐
          ↓                               ↓
┌─────────────────────┐       ┌─────────────────────┐
│ Обновление UI       │       │ Переключение        │
│ • local_ip_textbox  │   →   │ адаптера            │
│ • adapters_list     │       │ (если мониторинг    │
│   ComboBox          │       │  активен)           │
└─────────────────────┘       └─────────────────────┘
                                        ↓
                          ┌─────────────────────────┐
                          │ SwitchAdapterIfNeeded() │
                          │ • Остановка старых      │
                          │   workers               │
                          │ • Запуск новых workers  │
                          │ • Сохранение состояния  │
                          └─────────────────────────┘
```

## 📊 Интервалы обновления

| Компонент | Частота | Условие |
|-----------|---------|---------|
| **TicksLoop** | 1 сек | Всегда |
| **Проверка процесса** | 1 сек | Всегда |
| **LocalIP (новый процесс)** | Немедленно | При смене процесса |
| **LocalIP (тот же процесс)** | 30 сек | Кэш не истек |
| **UI синхронизация** | При изменении | IP изменился |
| **Переключение адаптера** | При изменении | IP изменился + мониторинг активен |

## 🎮 Практические сценарии

### Сценарий 1: Игра + переключение Wi-Fi → Ethernet
```
[T=0s]    Игра запущена, мониторинг активен, Wi-Fi (192.168.1.100)
[T=5s]    Пользователь подключает Ethernet
[T=6s]    LocalIP проверка (кэш)
[T=36s]   LocalIP проверка → новый IP: 192.168.0.50
[T=36.1s] UI обновлен
[T=36.2s] Адаптер переключен на Ethernet
[T=36.3s] Захват пакетов продолжается на Ethernet
```

### Сценарий 2: Смена процесса (браузер → игра)
```
[T=0s]   Chrome активен, LocalIP: 192.168.1.100
[T=1s]   Пользователь переключается на игру
[T=2s]   Процесс изменился → ResetCache()
[T=2.1s] LocalIP проверка → игра использует Ethernet: 192.168.0.50
[T=2.2s] UI обновлен
[T=2.3s] Адаптер переключен (если мониторинг активен)
```

### Сценарий 3: VPN включение
```
[T=0s]   Мониторинг на обычном адаптере (192.168.0.100)
[T=5s]   Пользователь включает WireGuard VPN
[T=35s]  LocalIP проверка → VPN IP: 10.8.0.5
[T=35.1s] UI обновлен → VPN адаптер
[T=35.2s] Захват переключен на VPN адаптер
```
