# 🔄 Автоматическое переключение адаптера — Краткая справка

## ✅ Что это дает?

Теперь приложение **автоматически переключает сетевой адаптер** для захвата пакетов при изменении сети, **не прерывая мониторинг**.

---

## 🎯 Как работает?

### Единая система проверки:

```
Каждую секунду → Проверка активного процесса
                    ↓
            Каждые 30 секунд → Проверка LocalIP
                    ↓
            Если IP изменился:
                    ├─ Обновление UI
                    └─ [НОВОЕ] Автоматическое переключение адаптера
```

**Всё происходит автоматически, без вашего участия!** 🚀

---

## 📋 Практические примеры

### 1️⃣ Переключение с Wi-Fi на Ethernet

```
До:
🎮 Игра запущена
📡 Wi-Fi адаптер (192.168.1.100)
✅ Мониторинг работает

[Вы подключаете Ethernet кабель]

Через 30 секунд:
📡 Автоматически переключен на Ethernet (192.168.0.50)
✅ Мониторинг продолжает работать БЕЗ перезапуска
✅ Статистика сохранена
```

### 2️⃣ Включение VPN во время игры

```
До:
🎮 Игра активна
📡 Обычный адаптер (192.168.0.100)

[Вы включаете WireGuard VPN]

Через 30 секунд:
📡 Автоматически переключен на VPN адаптер (10.8.0.5)
✅ Мониторинг через VPN
✅ Никаких разрывов
```

### 3️⃣ Динамическая смена IP

```
До:
📡 IP: 10.0.0.50

[DHCP назначает новый IP]

Через 30 секунд:
📡 IP обновлен: 10.0.0.100
✅ Захват пакетов продолжается
```

---

## ⏱️ Частота обновлений

| Событие | Время |
|---------|-------|
| **Смена активного процесса** | ⚡ Немедленно |
| **Тот же процесс + смена IP** | 🔄 До 30 секунд |
| **Переключение адаптера** | ⚡ ~100-200 мс |

---

## 🎮 Режимы работы

### Мультиадаптерный режим
**Когда активно:**
- Захват со всех адаптеров (Capture All Adapters)
- VPN Bypass (Basic или Advanced)

**Что происходит:**
- Все адаптеры перезапускаются
- VPN адаптеры имеют приоритет
- Автоматическая дедупликация пакетов

### Одноадаптерный режим
**Когда активно:**
- Обычный режим работы

**Что происходит:**
- Переключается только один активный адаптер
- Минимальная нагрузка на систему

---

## 🔍 Как проверить, что работает?

### Способ 1: Через UI
1. Запустите мониторинг
2. Посмотрите текущий адаптер в форме Settings
3. Переключите сетевой адаптер (Wi-Fi ↔ Ethernet)
4. Подождите 30 секунд
5. ✅ Адаптер в UI обновится автоматически

### Способ 2: Через Debug логи
Откройте Debug окно и найдите:
```
[SwitchAdapterIfNeeded] Adapter switch required: 192.168.1.100 -> 192.168.0.50
[SwitchAdapterIfNeeded] ✅ Adapter switched successfully to 192.168.0.50
```

## ⚠️ Что нужно знать

✅ **Работает только при активном мониторинге**  
  (кнопка Start нажата)

✅ **Кратковременная потеря пакетов** (~100-200 мс)  
  во время переключения - это нормально

✅ **Требуется включенный режим**:
  - Capture All Adapters, или
  - VPN Bypass, или
  - VPN Bypass Advanced

❌ **Не работает** если мониторинг остановлен

---

## 🧪 Быстрый тест

**Шаги:**
1. Запустите игру
2. Начните мониторинг (кнопка Start)
3. Переключите сетевой адаптер:
   - Отключите Wi-Fi и включите Ethernet, или
   - Включите VPN
4. Подождите до 30 секунд
5. Проверьте форму Settings → Adapter

**Ожидаемый результат:**
- ✅ ComboBox адаптера обновился
- ✅ Local IP изменился
- ✅ Мониторинг продолжает работать
- ✅ Статистика не сброшена

## 💡 Советы

### Для немедленного переключения:
Переключитесь на другое приложение, затем обратно в игру → это сбросит кэш и обновит IP мгновенно

### Если переключение не происходит:
1. Проверьте, что мониторинг запущен (IsTracking = true)
2. Убедитесь, что включен один из режимов:
   - Settings → Capture All Adapters
   - Advanced → VPN Bypass
3. Посмотрите Debug логи на наличие ошибок
