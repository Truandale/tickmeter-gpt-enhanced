# 🔄 Автоматическая проверка локального IP — Краткая справка

## ✅ Что изменилось?

Теперь приложение **автоматически переопределяет локальный IP** даже для одного и того же активного процесса.

---

## 📋 Как это работает?

### 1️⃣ **При смене процесса** (например, из браузера в игру)
- ⚡ **Немедленное обновление** IP
- 🔄 Кэш сбрасывается автоматически
- 📊 Новый IP определяется в течение секунды

### 2️⃣ **Для одного и того же процесса** (игра продолжает работать)
- ⏱️ **Периодическая проверка каждые 30 секунд**
- 🔍 Автоматически отслеживает изменения IP
- 💡 Полезно при переключении сетевых адаптеров

---

## 🎯 Практические сценарии

### Сценарий 1: Переключение с Wi-Fi на Ethernet
```
1. Игра запущена → IP: 192.168.1.100 (Wi-Fi)
2. Вы подключаете Ethernet кабель → новый IP: 192.168.0.50
3. В течение 30 секунд приложение автоматически обновит IP ✅
4. Мониторинг продолжит работать корректно
```

### Сценарий 2: Динамическое изменение IP (DHCP)
```
1. Процесс использует IP: 10.0.0.50
2. DHCP сервер обновляет адрес → новый IP: 10.0.0.100
3. Приложение переключится на новый IP в течение 30 секунд ✅
```

### Сценарий 3: Работа с VPN
```
1. Игра работает через обычный адаптер: 192.168.1.100
2. Вы включаете VPN → новый IP: 10.8.0.5
3. Приложение автоматически определит новый IP ✅
```

| Событие | Частота проверки |
|---------|-----------------|
| **Смена активного процесса** | ⚡ Немедленно |
| **Тот же процесс работает** | 🔄 Каждые 30 секунд |

## 🔍 Где это работает?

Автоматическая проверка активна при включенных настройках:
- ✅ **Capture All Adapters** (захват всех адаптеров)
- ✅ **VPN Bypass Basic** (базовый обход VPN)
- ✅ **VPN Bypass Advanced** (продвинутый обход VPN)

## 📊 Как проверить, что работает?

### Способ 1: Через Debug логи
Откройте Debug окно VS Code и следите за сообщениями:
```
[LocalIPDetector] Starting IP detection for process 'game.exe' (same process: True)
[LocalIPDetector] Определен IP по соединениям процесса game.exe: 192.168.0.50
[updateMetherStateFromActiveWindow] LocalIP changed: 192.168.1.100 -> 192.168.0.50
✓ Successfully updated LocalIP for process 'game.exe' to 192.168.0.50
```

### Способ 2: Через UI
1. Откройте форму настроек (Settings)
2. Посмотрите на поле **Local IP**
3. Смените сетевой адаптер
4. В течение 30 секунд IP обновится автоматически

- 📡 Определение IP основано на активных сетевых соединениях
